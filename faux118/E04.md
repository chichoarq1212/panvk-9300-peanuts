# PANVK 9300+ — Faux-compatible E04

E04 replaces the speculative E03 FP16 change and the unverified E02 descriptor expansion. It starts from the public Mesa 5a07217f + Zenithblue panvk-kbase-android v0.1.0-rc4 base used by the prior builds.

## Source-derived target

Faux123 v1.1.8 documents two changes:
1. Integer texel-buffer reads declared as float return stored bits rather than being numerically converted. The release says this fixes low FPS and wrong lighting in some Switch games.
2. When loaded through Android's system Vulkan loader, the driver does not expose present-wait/present-id/timing/swapchain-maintenance extensions that the loader manages.

E04 implements only the first behavior, narrowly for 32-bit float-result texel-buffer fetches, by selecting the NIR AUTO32 destination type and mapping that pseudo-type to BI_REGISTER_FORMAT_AUTO in LD_CVT. Both Bifrost and Valhall texel-buffer lowering call sites are patched; normal FP16, signed/unsigned, and non-texel loads retain their previous type selection.

## Why this is the useful next build

The earlier E03 FP16 rounding experiment did not reproduce the key behavior documented in Faux123 1.1.8. E04 removes that experiment and the E02 descriptor expansion to avoid carrying unrelated, unverified changes. The patch is deliberately limited to the core integer-texel-buffer behavior.

## Validation gates

- E04 patch anchors and AUTO32 type-selection host tests pass.
- Android ARM64 build and package checks pass.
- Package ABI comparison is useful but not proof of driver equivalence.
- Must still be tested in Peanuts Native on Xiaomi 14T Pro, especially a combat scene, for correct lighting, no white frames, no crashes, and matched FPS/frametime.
- Keep Faux123 v1.1.8 installed as the fallback. Do not uninstall it or change kernel/vendor/bootloader.

The Android-loader extension behavior is not included in E04; it requires a separate verified loader-detection implementation. No claim of exact equivalence, combat fix, or FPS gain is made before device testing.
