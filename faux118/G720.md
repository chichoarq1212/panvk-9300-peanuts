# G720 compatibility investigation (Faux123 v1.1.8)

The Peanuts host logs a shader library built for 64 lanes and hardware reporting a fixed 16-lane subgroup. The fallback is one-invocation subgroup operations in all six listed stages, not one physical thread for the entire shader. This can affect performance and semantics. It is not proof of the white-screen root cause.

The pinned translator (dm/gfx/tools/dmsh_xlate/Program.cs, igawa6/peanuts-native@719d4f7b6ffd) describes 32-lane guest warps and 64-lane host halves. Changing the library header to 16 or spoofing Vulkan subgroupSize is invalid. A correct 16-lane path needs semantic lowering of guest warp operations and tests for ballot, shuffle, vote, active masks, divergent control flow and compute workgroup memory. Do not enable a new path before equivalence tests.

The existing log also records scaled attachments returning to 1x when pixel fetches or mixed render passes require it. For a white-screen A/B, keep Faux123 and set game resolution to 1x for one run, with all other settings unchanged. This is a correctness test, not a proposed FPS gain. For NaN diagnosis use the existing combat profile separately. Compare ordinary runs only, with the same save, scene and camera. No source logs or game data are published.
