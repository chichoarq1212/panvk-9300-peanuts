# PANVK 9300+ — Peanuts Edition

Experimental Android ARM64 PanVK build for Mali G720 (PAN_ARCH 12). Based on Mesa and Zenithblue's public kbase patch series. E01 is diagnostic instrumentation, not a confirmed crash fix or FPS improvement. No device logs, game files or personal data are included.

Build baseline and E01 using GitHub Actions. Only install an actual validated ARM64 driver ZIP, not source code. Experimental drivers can crash or reboot devices. Retain a known working driver.

Upstream: https://github.com/zenithblue-oss/panvk-kbase-android and https://gitlab.freedesktop.org/mesa/mesa. Original licenses apply.
